## Как устроен бандл

- Это Kotlin/JS (IR), собранный webpack'ом. Свойства класса — `имя_1` (`f20_1`, `xii_1`), методы — короткие имена (`d21()`, `n7v()`).
- Методы вешаются через хелперы: `Zy(Класс).метод=function…` в модуле игры, `E(...)`, `Q(...)`, `xt(...)`, `Bn(...)` в других модулях.
- **Модулей много, и короткие имена в них повторяются.** `U$`, `g$`, `y$`, `GE` в разных местах файла — разные функции. Ищи определение рядом с местом использования или смотри импорты в шапке модуля: `y$=f.$_$.c`.
- `Z$("имя")` — обращение к ещё не инициализированному `lateinit`-свойству. Строка внутри — настоящее имя свойства из исходников. Лучшая подсказка, что за поле перед тобой (`Z$("weaponMount")`, `Z$("raycastShellCollisionFilter")`).
- `fn.callableName="имя"` — так игра подписывает лямбды и ссылки на функции. Имя настоящее.
- `toString` у data-классов выдаёт имена полей: `"ClientPointData [active = …"`, `"BattleMap ["`, `"Vector3 (x, y, z)"`.
- Enum: `new X("NAME", порядковый)`. В модуле игры порядковый номер — `.k3_1`, а `String(значение)` даёт имя (`"TEAM_A"`).
- Единицы движка — сантиметры. В расширении `UNIT = 0.01` переводит в метры.

## Камера

**Камера от третьего лица** (`M3`, «followCamera»). Регистрируется в мире через `kz1`.

| поле / метод | что |
|---|---|
| `qzs_1` | позиция на траектории 0…1 (по умолчанию из хранилища `battle.camera.pathPosition`, 0,175) |
| `tzv(t)` | задать позицию на траектории (зажимает в 0…1, сохраняет, пересчитывает через `C3`) |
| `tzs_1` | сплайн `W3`: ключи `wzu_1`, `xzu_1`, `yzu_1`, `zzu_1` (`H3 { uzu_1: дальность, vzu_1: высота }`) и **множитель дальности `azv_1`** (1 — обычная) |
| `W3.bzv(t, out)` | `out.uzu_1 = azv_1 · сплайн(t)` |
| `W3.c21()` | сбрасывает `azv_1` в 1 |
| `yzv(k)` | выставить `azv_1` |

Что сбрасывает дальность:
- `M3.aa2()` (подключение или сброс камеры) вызывает `tzs_1.c21()`, и `azv_1` становится 1;
- `WAn` каждый кадр вызывает `yzv(r1fs_1)`;
- `G3.mam` каждый кадр вызывает `tzv(...)`, и тот через `C3` пересчитывает `uzs_1` по текущему `azv_1`.

Поэтому расширение масштабирует **ключи сплайна** (`uzu_1` и `vzu_1` у `wzu_1..zzu_1`), а не `azv_1`: ключи игра никогда не сбрасывает. Применённое смещение — `uzs_1 { uzu_1: дальность, vzu_1: высота }`, его использует `$3()`. Столкновение камеры со стенами — `j3()`: `b9m(..., 16)`, при препятствии камера придвигается.

Управление в бою (`G3`): клавиши `cameraUp` / `cameraDown` и колесо меняют `qzs_1` на 0,6 в секунду.
`WAn` — контроллер свободной камеры (геймпад, `toggleAlterSpeed`): каждый кадр зажимает `azv_1` в 0,3…8 (константы `HAn`). В обычном бою он не активен.

Рендер-камера мира: `world.yyw_1`, `t35_1` — позиция, `u35_1` — поворот.

## Что расширение трогает в игре

Подробно — в README расширения, раздел «Отладка». Выключатели — `toCoords.off(...)`.

- **`cn`** — перехват `Function.prototype.callableName`.
  - **Версия 1** (accessor на прототипе + подмена `Object.defineProperty`): **с ней снаряды взрывались у дула**. С `toCoords.off("cn,listeners,wrapPoint")` стрельба нормальная. Точная причина не найдена.
  - **Версия 2** (текущая): первое присваивание сразу превращается в обычное собственное свойство функции; интересные функции кладутся в очередь и разбираются в нашем кадре; `Object.defineProperty` не трогаем. В бою ещё не проверена.
- **`listeners`** — обёртка `EventTarget.prototype.addEventListener` (только запоминает слушателей).
- **`wrapPoint`** — обёртка `initPoint`, чтобы получить позиции контрольных точек.
- **`pos`** — вызовы `getLocalTankPosition` / `isLocalTankAlive`.
- **`scan`** — обход памяти игры. Только чтение; заходит и внутрь `Map`.
- **Рейкасты движка** (`z9l` / `b9m`) по умолчанию выключены: `toCoords.engineRays(true)`.
- **Обёртку `updatePhysicsState` убрали:** она была нужна только для отладочного поля.

## Как искать после обновления игры

`grep` по этому файлу не работает: строки огромные. Ищи Python'ом и печатай кусок вокруг совпадения:

```bash
python3 - <<'EOF'
import re
s = open('main.js', encoding='utf-8', errors='replace').read()
for m in list(re.finditer(r'Z\$\("raycastShellCollisionFilter"\)', s))[:3]:
    print(m.start(), s[m.start()-800:m.start()+800]); print('-----')
EOF
```
